Uzdevuma nosaukums: 
Studentu reģistrācijas sistēma

Uzdevuma mērķis: 

    Izveidot CLI (command line interface) programmu studentu reģistrācijas sistēmu. Programmai jāļauj lietotājam reģistrēt jaunus lietotājus. Datus jāglabā csv failā.
    Izpētīt .csv formātu, saprast to pielietojumu, un apstrādāt dotos failus izmantojot programmēšanas valodu Java.
    Izpētīt paņiemienus kā var pārbaudīt vai lietotāja ievade bija korekta un atbilst programmas prasībām (RegEx).

Uzdevuma prasības:

    Programmai jāļauj lietotājam reģistrēt jaunus studentus, ievadot šādu informāciju:
        Vārds
        Uzvārds
        E-pasts
        Personal kods
        Reģistrācijas datums un laiks
    Jaizveido ievaddatu prasības (piem. "Vārds" var saturēt tikai burtus un minimālais String garums ir 3 simboli). Jāpielieto līdzīgas pārbaudes visiem ievaddatiem.
    Datu atspoguļošanu jāizveido ar formatētu izvadi, piemērs uz attēla.
